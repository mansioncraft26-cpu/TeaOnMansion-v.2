PRODUCT SETUP

Product Options Manager

Manage sizes, sweetness, extra shots, and map each option to ingredient stock adjustments.

Stock rule: the normal recipe is deducted first. Option mappings are additional quantity adjustments per cup: positive adds consumption; negative reduces consumption. Example: if the base recipe uses 20 ml syrup, Sweetness 50% can map syrup to -10 ml. Use the ingredient's own unit (g, ml, pcs).

1. Add option group

2. Add option

3. Enable group for a drink

4. Map an option to stock

Each mapping adjusts stock use for that option. Use positive values to consume more and negative values to consume less than the base recipe.
